# Death Replay（死亡回放）使用说明

版本 0.1.0 · Minecraft Java 1.21.11 · Fabric · 纯客户端

---

## 1. 这个模组是干什么的

死了之后，想知道"我到底是怎么死的"。原版的死亡界面只能原地转头，而且一秒后周围的怪和玩家就全消失了。这个模组做两件事：

**死前回放。** 模组在你活着的时候一直悄悄记着最近 30 秒发生的事。死了以后可以把这 30 秒重新放一遍：

- 你自己（带皮肤和装备）怎么走、怎么打、怎么倒下
- 周围的怪、玩家、动物、掉落物、箭的位置和动作
- 方块在哪一刻被放下或被挖掉
- 粒子、声音、爆炸、受伤闪红、暴击星星、着火
- 可以暂停、拖进度条、换视角：第一人称（你当时眼睛看到的）、第三人称、自由飞行
- 死亡界面上能看，重生之后也能看，存成文件后重启游戏还能看

**死亡界面自由视角。** 还没点重生的时候，镜头不再钉在尸体上：

- 死亡界面一出现，镜头自动退到尸体后上方
- 可以绕着尸体转，也可以像旁观模式一样自由飞（能穿墙）
- 打死你的怪和你的尸体会"定格"在原地让你看清楚（原版这时候已经是一片空地了）

**它不做的事：**

- 不发任何数据包给服务器，不注册任何通信频道。服务器看不出你装了它。
- 不显示死亡点"现在"的情况。重生之后你能看的只有录像，录像截止到死后 0.75 秒。
- 不改变游戏玩法，不模拟任何操作。

## 3. 安装

**需要：**

| 项目 | 要求 |
|---|---|
| Minecraft | Java 版 1.21.11 |
| Fabric Loader | 0.19.5 或更高 |
| Fabric API | 必须装 |
| Java | 21 或更高 |
| Mod Menu | 可选。装了就能在模组列表里点开设置；不装模组照常工作 |

**步骤：**

1. 把 `deathreplay-0.1.0.jar` 放进游戏的 `mods` 文件夹（PCL2 开了版本隔离的话，是那个实例自己的 `mods` 文件夹）。
2. 确认 `mods` 里有 Fabric API。
3. 启动游戏。只需要装在客户端，服务器上不用装，也不要装。

目前还没有发布到 Modrinth。jar 要自己构建：在项目目录运行 `.\gradlew build`，成品在 `build/libs/deathreplay-0.1.0.jar`。

## 5. 怎么用

### 5.1 死了之后会看到什么

死亡界面照常出现，有三处不同：

1. **画面**不再是从尸体眼睛看出去，而是从你背后上方看着自己倒下。大约 1 秒后，周围的怪和你的尸体会定格在原地。
2. 原版的"重生""返回标题画面"下面多了一行两个按钮：**回放** 和 **观察战场**。
3. 再下面一行是 **保存回放**。

"回放"按钮要等大约 1 秒才亮（模组在这 1 秒里把录像收尾、拍下周围地形）。

### 5.2 观察战场

点 **观察战场**。红色滤镜、按钮、快捷栏、聊天栏都会藏起来，鼠标直接控制视角。屏幕上方会显示当前视角和按键提示。

按 **F5** 在三种视角间循环：

| 视角 | 怎么操作 |
|---|---|
| **第三人称** | 镜头拴在尸体周围。动鼠标绕着看，滚轮拉近拉远（1.5 到 20 格）。镜头会被墙挡住，不会埋进方块里 |
| **环绕** | 和第三人称一样，但镜头自己慢慢绕着尸体转（每秒 15 度）。动鼠标可以调俯仰角度 |
| **自由视角** | 随便飞。移动键飞行，空格上升，Shift 下降，按住 Ctrl 加速，滚轮调速度（每秒 2 到 40 格，默认 10）。可以穿墙，没有距离限制。飞到没加载的地方就是空的 |

按 **Esc** 回到死亡界面。重生按钮会像刚死时那样先灰 1 秒，防止误点。

你看到的怪和尸体是**死后那一刻的定格**，不是实时的。原版服务器在你死后 1 秒就不再给你发周围实体的信息了，所以这时候其实没有"实时"可看。

### 5.3 看回放

**从哪进：**

- 死亡界面：点 **回放**
- 重生之后：按 **F6**（重生时聊天栏会提示一次）
- 任何时候：设置界面里的 **已保存的回放…**

**界面长这样：**

- **最上面一行**：当前状态（播放中 / 已暂停 / 已结束）和当前视角。
- **进度条**：白色是已经播过的部分，红色竖线是你死的那一刻，白色小滑块是现在的位置。下面一行字写着"死亡前 X 秒"或"死亡后 X 秒"。
- **最下面一排按钮**：从头播放、播放 / 暂停、当前视角（点一下换下一个）、保存、关闭。
- 按钮上方一行是当前视角下的操作提示。

**操作：**

- 鼠标是自由的，可以点按钮、点进度条。
- **拖进度条**：按住左键在进度条上拖，画面跟着走。拖的时候自动暂停，松手后如果之前在播放就继续播。
- **转视角**：按住**鼠标右键**拖动。松开右键，鼠标回到原来的位置。
- 播到结尾会自动停下。这时再点"播放"或按回车，会从头再放一遍。

**三种视角**（F5 或点底部的视角按钮，按 第三人称 → 自由视角 → 第一人称 的顺序循环）：

| 视角 | 说明 |
|---|---|
| **第三人称**（默认） | 镜头跟着录像里的你。右键拖动绕着看，滚轮拉近拉远 |
| **自由视角** | 随便飞，操作和"观察战场"的自由视角一样，只是转视角要按住右键 |
| **第一人称** | 你当时眼睛看到的画面。看不到自己的手和手里的东西 |

**关闭回放**：按 Esc 或点"关闭"。画面立刻回到真实的游戏世界。

### 5.4 看回放时要知道的事

- **回放是在一份地形副本里放的，真实世界一点没动。** 回放里方块被挖掉、怪被打死，都只是录像。关掉回放，世界就是它现在真实的样子。
- **看回放的时候游戏没有暂停。** 你的角色还站在原地。如果你是重生后活着看的，旁边有怪的话会挨打。被打死时回放会自动关掉，出现死亡界面。**找个安全的地方再看。**
- **点重生的那一刻，正在放的回放会关掉。** 重生后按 F6 重新打开就行。
- 回放里能看到的范围是死亡点周围 **8 个区块**（128 格）以内的地形，和你周围 **64 格**以内的实体。飞出这个范围是空的。
- 录像一直留在内存里，直到你下一次死亡把它换掉，或者你退出这个服务器 / 存档。想长期留着就保存成文件。

### 5.5 保存回放和看存档

**保存：**

- 死亡界面点 **保存回放**，或者回放界面点 **保存**。
- 存好后按钮变灰，聊天栏会告诉你文件名。
- 也可以在设置里打开 **自动保存回放**，每次死亡都自动存。

**文件在哪：** 游戏目录下的 `deathreplay` 文件夹（和 `mods`、`saves` 同级），文件名形如 `death_2026-10-01_17-10-13.nbt`，名字里是死亡的日期和时间。

**文件多大：** 平坦世界大约 50 KB。普通地形没有实测过，估计几百 KB 到几 MB，大头是地形。开了自动保存又经常死的话，记得偶尔清一清。

**看存档：**

1. 先进入一个世界（任何世界都行，不必是当时死的那个，也不必在同一个维度）。
2. 打开设置，点 **已保存的回放…**；或者在内存里没有录像的时候按 F6。
3. 列表最上面是"上次死亡（内存中）"，下面是存档，新的在前，每页 5 个，按日期时间和文件大小显示。
4. 点一个就开始播放。关掉回放会回到这个列表。
5. "文件夹"按钮直接在资源管理器里打开 `deathreplay` 文件夹，方便删文件。

**存档的限制：**

- 只能用**同一个 Minecraft 版本**打开。别的版本存的文件会被拒绝并提示。
- 在主菜单（没进世界）不能播放，列表里的按钮是灰的。
- 换了一个装着不同模组的服务器后，含模组方块或模组生物的存档可能读不出来（会提示，不会崩溃）。

## 6. 设置

**怎么打开：**

- 装了 Mod Menu：主菜单或暂停菜单点"Mods"→ 选中 Death Replay → 点右上角的设置图标。
- 没装 Mod Menu：在按键绑定里给"死亡回放 → 打开设置"绑个键，游戏里按它。

**选项：**

| 选项 | 默认 | 说明 |
|---|---|---|
| 录制时长 | 30 秒 | 保留死亡前多少秒。5 到 120 秒，每档 5 秒。越长占内存越多 |
| 自动保存回放 | 关 | 开了以后每次死亡自动存成文件 |
| 回放默认视角 | 第三人称 | 打开回放时先用哪个视角。可选第一人称、第三人称、自由视角 |
| 重生后提示回放按键 | 开 | 重生后在聊天栏提示一行"按 [F6] 观看刚才的死亡回放" |
| 死亡界面自由视角 | 开 | 关掉后死亡界面的画面和原版完全一样，没有"观察战场"按钮，也没有定格。"回放"和"保存回放"按钮还在 |
| 死亡界面默认视角 | 第三人称 | 死亡界面刚出现时用哪个视角。可选第三人称、环绕、自由视角 |

下面还有 **已保存的回放…**（打开存档列表）和 **完成**。

鼠标停在选项上会显示说明。改动立刻生效，关闭设置界面时写进 `config/deathreplay.json`。

## 7. 能在服务器上用吗

模组做的全部事情是：记下服务器本来就发给你的数据，在你自己的电脑上重放。它不发任何包，不注册任何频道，不伪造任何操作。

这一点实测过：在开发环境的自动测试里，死亡界面、回放、观察战场一共开了 17 秒，客户端发给服务器的只有原版每一刻自带的心跳包（`ClientTickEndC2SPacket`），没有别的。重生后活着看回放时，多出来的也只是原版客户端本来就在发的位置包。

和 Freecam 的区别：Freecam 是你活着的时候把镜头飞出去侦查。这个模组的自由视角只在你**死了以后**才有，看的是定格的画面和录像，飞得再远也只能看到你死之前客户端已经收到的东西。

是否允许使用，最终由各个服务器自己的规则决定。

## 8. 对性能的影响

- **平时游玩**：录制记的是数据不是画面。实测周围 34 个实体时每一游戏刻多花约 22 微秒，周围 186 个实体时约 56 到 71 微秒。一个游戏刻是 50000 微秒。
- **死亡的那一刻**：要拍一次地形快照。平坦世界 289 个区块约 3 毫秒。山地、洞穴这类复杂地形会更久，没有实测过。
- **打开回放**：要搭一次地形副本（平坦世界约 15 毫秒），然后重新生成画面，和按 F3+A 重载区块的感觉差不多。关闭回放时同样会重新生成一次真实世界的画面。
- **内存**：一段录像连同地形快照留在内存里，直到下次死亡。

## 9. 已知限制

- 回放速度固定 1 倍，没有慢放和快进。
- 第一人称回放里看不到自己的手和手持物品。
- 你自己的脚步声、自己挥剑的声音不在回放里（服务器不会把你自己的动作声音发回给你，所以没录到）。别人的声音、怪的声音、方块的声音都在。
- 钓鱼浮标、末影龙的身体各部分回放不出来。
- 箱子、告示牌这类"带内容的方块"如果是在录像的 30 秒内被拆掉的，回放会把方块放回去，但里面的内容（告示牌上的字、箱子里的东西）回不来。
- 服务器开了"立即重生"的话没有死亡界面，只能重生后按 F6 看。
- 录制范围每刻最多 512 个实体，超过的不录（刷怪塔之类的地方）。

## 10. 目前的验证情况

写这份说明时（2026-10-01），模组通过了自动自检（128 项检查，30 张截图，每张都看过），但：

- **还没有人用真手玩过。** 鼠标手感、方向、灵敏度都没有经过人的确认。
- **声音没有人听过。** 自检只能确认声音包被录下并重放了。
- **没有在真实的游戏实例里跑过**，只在开发环境里跑过。尤其是和 Sodium、Iris、Voxy 这类接管渲染的模组一起用会不会出问题，完全未知。回放需要把画面临时指向另一份地形，这正是最可能和渲染模组冲突的地方。
- **没有在多人服务器上测过。**

遇到问题时，日志在 `logs/latest.log`，崩溃报告在 `crash-reports/`。

## 11. 常见问题

**"回放"按钮是灰的。**
刚死的第 1 秒内是正常的，等一下就亮。

**按 F6 没反应。**
F6 只在没有打开任何界面时有效。死亡界面上请点"回放"按钮。也可能是 F6 和别的模组冲突了，去按键绑定里看"死亡回放"分类。

**按 F6 出来的是一个列表，不是回放。**
内存里没有录像（比如刚启动游戏、刚换了服务器，这次进来还没死过）。列表里有存档的话可以点存档看。

**回放里远处是空的。**
回放只有死亡点周围 8 个区块的地形。

**死亡界面上的怪不动。**
那是定格的最后一帧，本来就不动。想看它们怎么动的，点"回放"。

**死亡界面我想要原版的样子。**
设置里把"死亡界面自由视角"关掉。

**重生后那行聊天提示很烦。**
设置里把"重生后提示回放按键"关掉。

**存档列表里点了提示"无法读取"。**
那个文件是别的 Minecraft 版本存的，或者文件坏了，或者当时的服务器有现在没有的模组内容。
